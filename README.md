# SAR_InSAR_Subsidence_Monitoring
應用ASF之NISAR或ARIA-S1之GUNW資料集推算AOI的大區域長時間地層沉陷

以下成果為快速生成，資料來源為稀疏18個月Sentinel-1 SAR觀測資料，部分貼海區域呈現不合理地形起伏係因環境變化頻次較高。
